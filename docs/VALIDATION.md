Последующие изменения относятся к тестовому окружению, подписанному артефакту, сценарию установки и медиа.

[Проверка реального обновления](https://github.com/PANDORA615/Immunoblockers/actions/runs/43475039870). SHA256 подписанного APK: `024215cfe887c89aa3670ac46f0cacd92578511f8150a03e09bfb8e88c13d6a2`. Проверены package name, versionCode 5, минимальная версия API 26, четыре ABI, подпись и выравнивание APK.

## Исправления

На пустой главной одна кнопка добавления. Край прокручиваемого списка имеет мягкую маску под фиксированной шапкой и над нижней панелью; карточки остаются внутри области списка.

Обои приложения отделены от подложки виджетов рабочего стола. Системный выбор изображения копируется во внутреннее хранилище, сохраняется в DataStore и отображается в обеих стилях интерфейса. Есть предпросмотр и удаление. При обновлении ранее выбранная подложка подхватывается как обои. Если один файл используется несколькими настройками, удаление одной ссылки сохраняет файл для остальных. Текст получает цвет текущей темы, включая тёмный Material.

График показывает количество приёмов по вертикали, даты и дни недели, числитель «принято» и знаменатель «запланировано». Нажатие на день раскрывает все четыре состояния в числах; пустой период имеет отдельное пояснение.

## Проверки данных

Инструментальные проверки копируют фото, удаляют исходник, проверяют отображение фона, пересоздание Activity, обе стилистики, совместное использование и удаление файла. Двухфазная проверка с `am force-stop` проверяет восстановление пути к обоям, профиля, записи журнала и прежнего уникального задания опроса. Сохранены проверки Room, опросов и семи настоящих провайдеров виджетов обоих размеров, приватности и действий.

Отдельный сценарий устанавливает опубликованный APK 0.4.0, создаёт профиль через интерфейс, сохраняет в его базе контрольное лекарство, принятую дозу и запись самочувствия, затем выполняет `adb install -r` подписанного APK 0.4.1. После запуска проверяет профиль, строки Room v2 и единственную кнопку добавления. Дополнительно подставляет старую настройку widgetImage без нового ключа wallpaperPath и проверяет сообщение «Обои выбраны» в новом разделе. Корневой доступ используется только внутри одноразовых эмуляторов для подготовки и проверки тестовых данных; ключ подписи туда не передаётся.

## Ограничения

Проверки выполняются на эмуляторах Android 8/API 26 и Android 15/API 35. Поведение конкретного лаунчера, прошивки и живых обоев не заявляется как проверенное на физических телефонах. 0.3.0 подписана утраченным прежним ключом и несовместима с веткой 0.4.x; обновление 0.4.0 → 0.4.1 использует прежний сертификат 0.4.0.
