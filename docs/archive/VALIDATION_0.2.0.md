# Проверки Immunoblockers 0.2.0

## Сборка и автоматические сценарии

[CI: 224567e](https://github.com/PANDORA615/Immunoblockers/actions/runs/43166546468).

`./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease assembleDebugAndroidTest` — успешно: оба APK и пакет инструментальных тестов собраны, lint без ошибок, 18 unit-тестов без ошибок.

`./gradlew connectedDebugAndroidTest -Pandroid.injected.androidTest.leaveApksInstalledAfterRun=true` — по 11/11 успешно на AOSP Android 8.0/API 26 и Android 15/API 35, x86_64, профиль Pixel 2, KVM в GitHub Actions. Анимации отключены для функциональных проверок. На API 35 выданы разрешения уведомлений и exact alarm; для тестового AppWidgetHost разрешено связывание виджетов. Это тестовые настройки эмулятора, приложение не выдаёт себе разрешений.

- 11 тестов расписаний: дни недели, курс, пауза/архив, редактирование, DST gap/overlap, зона, snooze через полночь, стабильные ID.
- 1 тест контраста палитры в обеих темах на разных seed.
- 6 тестов аналитики: точные десятичные суммы, разные единицы и ID, отсутствие отметки вчера/ожидание сегодня, пустые дни, исходная дата перенесённого приёма, защита от некорректной дозы.
- Room: конкурирующие отметки, архив, снимок истории, перенос и устаревшая отмена исправления.
- AlarmManager → BroadcastReceiver → уведомление при закрытой Activity; перенос и повторное действие «Принято».
- Виджеты: три зарегистрированных провайдера, реальные RemoteViews, скрытие доз/названий, исключение лекарств на паузе. Настоящий AppWidgetHost связывается с провайдером и отправляет двойное действие; в БД одна отметка с прежней дозировкой.
- Compose: форма сохраняется при пересоздании Activity; создание → отображение → отметка; тема и экран восстанавливаются. Настройка поля сохраняется, журнал показывает историческую дозу, конкурентные изменения дизайна сохраняют независимые значения.

## Границы проверки

Подтверждены функциональные сценарии на эмуляторах, не frame timing. Показатель jank<5%, работа 60/90/120 Гц на физическом телефоне, полный ручной TalkBack/200% шрифт и разнообразные OEM-лаунчеры не измерены. График увеличивает ширину столбцов с масштабом шрифта, поля и списки прокручиваются. Текст виджетов ограничен их размером; полные записи доступны в приложении.

Полноценный reboot, OEM Doze/энергосбережение и ручной отзыв разрешений после обновления требуют дополнительной проверки на устройствах. Виджеты обновляются после действий и периодически по запросу Android; доставка напоминаний зависит от системных разрешений и ограничений, как в 0.1.0.

Локальная полная сборка прерывалась перезапуском среды и изменением исходников во время работы; успешной целиком она не объявляется. Основание результата — чистые сборки и инструментальные проверки CI одного коммита. [Отчёт 0.1.0](archive/VALIDATION_0.1.0.md).
