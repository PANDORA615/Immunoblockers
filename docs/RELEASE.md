Immunoblockers 0.3.0 — стеклянный интерфейс, OTA и режим пары.

**Скачать:** `Immunoblockers-0.3.0-universal.apk` — один APK для Android 8.0 и новее, ARM и x86. Устанавливается поверх 0.1/0.2 с сохранением истории.

- Выбор Liquid Glass + Glassmorphism или Material 3. Плавающий индикатор вкладок и мягкие переходы по мотивам присланного видео. Округлый Nunito с полужирными заголовками, сохранены свои цвета и уменьшение движения.
- Пять виджетов рабочего стола: ближайший приём, день, журнал, неделя и запасы. По умолчанию отметка требует подтверждения.
- Новые карточки главного экрана: календарь, остатки лекарств, самочувствие, партнёр, проверка напоминаний и OTA.
- Запасы уменьшаются по новым подтверждённым приёмам; отмена возвращает количество. Есть порог предупреждения.
- Режим «Мы вдвоём»: добровольный обмен лекарствами/дозировками, последними отметками и самочувствием; сообщения поддержки. Отдельные разрешения передачи, шифрование, время обновления и разрыв пары.
- OTA через GitHub Releases: ручная загрузка, проверка SHA256 и сертификата, установка с подтверждением Android.

**Для синхронизации нужен ваш HTTPS-сервер.** Постоянный публичный сервер пока не развёрнут. Серверная часть и инструкция Docker/Caddy находятся в `server/`. Локальные функции и OTA работают без него. Фоновый обмен периодический, может задерживаться Android.

[Как пользоваться](https://github.com/PANDORA615/Immunoblockers/blob/main/docs/FEATURES_0.3.0.md). Дозировки назначает врач; приложение хранит расписание и отметки.

Проверки: 20 unit-тестов, lint и по 15 инструментальных тестов на Android 8/API 26 и Android 15/API 35. Сервер проверен также внутри Docker.
