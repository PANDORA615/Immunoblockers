# Сервер обмена для двух устройств

Сервер готов к самостоятельному размещению. Постоянный сервер для этого репозитория пока не предоставлен. Нужны VPS с Docker Compose, домен с A/AAAA-записями на VPS и открытые TCP 80/443. Удалите неверную AAAA-запись, если IPv6 не работает.

```sh
git clone https://github.com/PANDORA615/Immunoblockers.git
cd Immunoblockers/server
PAIR_DOMAIN=pair.example.com docker compose up -d --build
```

Замените pair.example.com своим доменом. Caddy получает и обновляет TLS-сертификат. В приложении введите `https://pair.example.com`. HTTP и сертификаты без доверенного центра в release-приложении не поддерживаются. Порт 8080 наружу не публикуется. Не включайте логирование заголовков Authorization и тела запросов на прокси.

Ключи комнат генерируются приложением, отдельной административной настройки нет. В SQLite лежат зашифрованные снимки, хеши токенов и метаданные. Каждая комната имеет два независимых права записи; третий участник отклоняется. При разрыве содержимое удаляется, остаётся идентификатор отозванной комнаты и хеш авторизации, чтобы старое приглашение не создало её заново. Отключение передачи удаляет поля из следующего успешно отправленного снимка. Временная недоступность сервера не блокирует локальные напоминания.

Неактивные комнаты старше семи суток очищаются при следующем запросе к серверу. Сам сервер и прокси видят IP/время запросов; схема не скрывает метаданные. Код приглашения содержит общий секрет: передавайте только выбранному партнёру. Обладатель сервера может остановить или задержать обмен; приложение показывает время последнего обновления.

Тесты: `python -m unittest discover -s server` из корня проекта. CI отдельно запускает изолированный HTTPS-сервер и Android-тест двух клиентов. Тестовый центр сертификации включён только в debug, закрытый ключ генерируется временно в CI. Release не доверяет этому центру.

Обновление сервера: `git pull`, затем `docker compose up -d --build` с тем же PAIR_DOMAIN. Данные находятся в Docker volume pair-data. Для полного удаления: `docker compose down -v` (также удалит TLS-данные). Не делайте это для обычного обновления.
